# 🏡 PropPriceAI

## ✨ Project Tagline
*"From simple regression to powerful ensembles — predicting house prices made smarter."*

---

## 📌 Overview
This project applies machine learning to predict house prices.  
I began with **Linear Regression** to establish a baseline model, and later implemented a **Random Forest Regressor** to capture non‑linear relationships and improve accuracy.  

The README documents the journey of model evolution, workflow improvements, and reproducibility practices.

---

## ⚙️ Workflow
1. **Data Preprocessing**
   - Handling missing values
   - Encoding categorical variables
   - Scaling numerical features
2. **Feature Engineering**
   - Square footage
   - Number of bedrooms/bathrooms
   - Location attributes
3. **Model Training**
   - Linear Regression (baseline)
   - Random Forest Regressor (improved performance)
4. **Evaluation**
   - RMSE
   - R² score
   - Cross‑validation

---

## 📊 Results
- **Linear Regression**: Provided a simple, interpretable baseline.  
- **Random Forest**: Delivered stronger predictive performance by leveraging ensemble learning.
